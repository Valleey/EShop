# EShop
Un program simplu pentru un magazin online. Programul vine cu functiile: 

Autentificare si creare cont.

Rasfoire prin catalogul virtual de produse, acestea pot fi adaugate de administratorul magazinului (User: Admin, parola: ADMIN)

Optiune de oferte si reduceri.

Posibilitatea clientului de a adauga produse in cosul de cumparaturi si a plati prin cash sau card.

Data de baze cu utilizatorii inregistrati.

Data de baze cu produsele disponibile.
